# a011 (First principles / Open questions first / Clarity)
First principle: friction is dimensionless. Friction% = (S*C*q)/(D*C*q) = S/D. It does not depend on lot size or contract size at all. Therefore the 15% rule is a pure stop-distance constraint: D >= 6.67*S. On SP500 (S=0.83) D>=5.53 pts - trivially satisfied. On ETH (S=3.0) D>=20.0 pts = 2.50 ATR - which is what kills ETH, not the walls. On SOL (S=0.28) D>=1.867 = 4.48 ATR - wider than SOL's whole 4.4 ATR L3 corridor. This single identity explains why the desk keeps landing on STAND ASIDE. Answer: SP500.p BUY_LIMIT 7750.70 SL 7737.30 TP 7794.00 0.10 lots.

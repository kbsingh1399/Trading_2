## Dimension 3 — covariance, sizing, drawdown

The core signed-notional covariance math is correct. With existing vector v and signed candidate notional n in coordinate j:

```text
variance_before = v' * Sigma * v
A = n^2 * Sigma[j,j]
B = 2 * n * (Sigma[j,:] * v)
variance_after(scale) = variance_before + A * scale^2 + B * scale
incremental_variance = A * scale^2 + B * scale
```

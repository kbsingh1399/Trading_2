### 3. THE ARCHITECTURAL CHALLENGE: DESKTOP DEPENDENCY ABSTRACTION
Currently, our institutional trading loop (`Terminal/OF_Strategy.py`) runs on a local Windows machine. We require you to design a **production-grade cloud architecture** that allows the entire institutional decision-making and execution chain to run **100% headless in an isolated cloud/container environment**, completely eliminating local desktop dependencies.

#### The 3 Desktop Dependencies that Currently Bind Execution:
1. **Dependency 1: Windows MetaTrader 5 Desktop IPC (`Terminal/MT5_Execution_Bridge.py`):**
   - The official `MetaTrader5` Python package requires Windows and communicates via named pipes / shared memory with a local running desktop `terminal64.exe` GUI process.
   - In cloud containers (Linux Docker, AWS ECS, Google Cloud Run), there is no Windows GUI or native desktop terminal.
   - **Requirement:** Design a clean, polymorphic execution abstraction layer (`ExecutionBridgeBase`) that decouples trading logic from the Windows-only `MetaTrader5` package.
2. **Dependency 2: Browser CDP Orderbook Scraping (`Terminal/Chrome_Terminal.py`):**
   - Currently, `Chrome_Terminal.py` connects over Chrome DevTools Protocol (CDP port 9222) to a running Chromium browser instance to scrape and expose L2/L3 orderbook depth and whale clusters on `http://localhost:8095`.
   - In headless cloud deployments, running a full desktop browser with graphical rendering is resource-heavy, fragile, and prone to memory leaks.
   - **Requirement:** Fully absorb orderbook depth aggregation and whale cluster detection directly into pure asynchronous Python inside `Terminal/Data_Factory/streams.py` and `factory.py`, streaming directly from Binance, Coinbase, and Hyperliquid WebSockets without any browser dependency.
3. **Dependency 3: Local Process Lifecycle & Scheduling:**
   - Currently, cycles are orchestrated via local Windows tasks and background schedules.
   - **Requirement:** Design a robust, containerized 24/7 service runtime with auto-reconnection, heartbeat health monitoring, and deterministic 15-minute candle boundary execution (:14, :29, :44, :59 UTC).
